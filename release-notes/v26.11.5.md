# Multi CLIProxyAPI 26.11.5

本版本修复 CPA 升级自检的启动时序问题，并调整升级失败后自动备份的锁定规则。

## 修复与改进

- 修复 CPA 已启动 HTTP 服务、配置文件监听器尚未就绪时，临时测试 Key 的首次重载被遗漏，导致 `/v1/models` 持续返回 401 并误触发升级回滚的问题。连续拒绝后有限次轮换临时 Key，触发实际配置变更并重新验证。
- 自检结束、取消或写入响应中断时，清理本次创建的所有临时 Key，保留原有及验证期间新增的其他 Key。永久鉴权失败和 HTTP 403 仍会使升级失败并回滚。
- CPA 或插件升级失败后，保留的自动备份会自动解锁，并禁止再次锁定；备份阶段中途失败、回滚受阻和重启恢复均适用。
- 失败升级留下的备份会跳过后续统一升级及插件部署。界面显示“备份不可锁定”，可直接管理或按原有删除流程清理。
- 总控、Web 界面及版本文档统一更新至 26.11.5。

## 验证

- CPA 自检、实例服务、升级与插件相关后端测试 114 项通过；相关前端测试 48 项通过，TypeScript 检查及前端构建通过。
- Linux 实测 CPA 8.0.76 + Key Billing 1.5.3：复现启动后连续 401，轮换临时 Key 后约 2 秒通过自检，结束后仅保留原有 Key。
- Linux amd64 单文件二进制通过启动、健康接口、内嵌页面及版本、管理员登录和实例 API 冒烟验证。
