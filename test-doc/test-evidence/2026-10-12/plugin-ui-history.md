# 插件模块 UI 与部署记录删除

日期：2026-10-12。

- UI 采用现有系统的模块标题、卡片、表格、表单和状态标签，部署记录展示创建时间、实例数量及可折叠详情，支持选择未锁定实例。
- 删除已结束记录需页面确认；只删除完成或失败的任务。排队、执行中和待恢复的任务由前后端同时保护。删除不改变插件文件、配置及备份，且写入审计日志。
- 接口为 `DELETE /api/plugins/jobs/:id`，需管理员会话，拒绝跨来源请求，记录不存在返回 404，活动任务返回 409。
- Linux 后端全套 122 / 122、前端全套 32 / 32 通过；前端 TypeScript 检查和生产构建成功。测试覆盖删除确认、取消、失败保留记录、活动任务保护、身份校验、审计及文件保留。
- 本地浏览器使用独立内存测试数据核对页面、实例选择、删除确认框及 390px 窄屏；表格内部滚动，页面无整体横向溢出。截图为 `plugin-ui.jpg`，其中实例及记录为 UI 验证数据。
- Ubuntu 22.04.5 amd64 / Node.js 24.18.0 编译独立二进制；冒烟检查验证独立启动、健康检查、登录、插件目录/历史接口及内嵌新版插件 CSS。临时进程和临时数据已清理，没有启动系统服务或修改既有实例。
